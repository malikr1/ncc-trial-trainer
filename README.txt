NCC Trial Trainer — GitHub Pages package

UPLOAD THESE FOUR FILES TO THE ROOT OF A PUBLIC GITHUB REPOSITORY:
- index.html
- manifest.webmanifest
- sw.js
- .nojekyll

Then:
1. Repository → Settings → Pages.
2. Build and deployment → Source: Deploy from a branch.
3. Branch: main, folder: /(root), then Save.
4. Open the HTTPS github.io address GitHub provides.
5. On iPhone/iPad, test voice in Safari first. Allow microphone/speech access when prompted.
6. On Android, Chrome is the recommended first test.

The ordinary trainer still works if speech recognition is unavailable.
Study progress remains in that browser/device's localStorage.

IMPORTANT:
GitHub Pages sites are public. Do not add patient information or other sensitive data.
